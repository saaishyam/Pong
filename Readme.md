# Pong

**Pong** is a game where you control a paddle and hit the ball around untill the ball crosses the paddle.

This was made as a learning project which was made by using Raylibs library.

## Features

    *Basic movements
    *Collision detection
    *And so called CPU movement

# Running Pong


Compile main.c
```bash
gcc main.c -o game -lraylib -lGL -lm -lpthread -ldl -lrt -lX11   
```

Run main.c

```bash
./game
```
